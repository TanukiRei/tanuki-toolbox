# dsh-tanuki-toolbox · 黎猫工具箱

**简体中文** · [English](README.en.md)

<img src="assets/toolbox.png" width="144" alt="Tanuki Toolbox">

为 **DeepSeek Harness（DSH）** 提供可独立开关的界面与交互增强：快捷栏、起始页、对话框、模型设置、消息通知与插件管理，并提供 Windows 启动保护。支持日间／夜间主题，随 DSH 语言切换中文或英文。

当前版本：**0.10.3**。提供模型设置、中枢速度控制、通知与 Windows 后台保护重启等功能。本项目为社区插件，非 DeepSeek 官方产品。

## 安装

在 DSH 的「插件 → 添加插件」中填写仓库地址：

```text
https://github.com/TanukiRei/dsh-tanuki-toolbox
```

安装后启用「黎猫工具箱」，再按需要开关各组件。仓库包含构建结果，不需要在安装时编译。直接填写仓库地址需要本机可用的 Git；如果电脑没有 Git，请使用 [最新 Release 说明](https://github.com/TanukiRei/dsh-tanuki-toolbox/releases/latest)中的「免 Git 安装地址」。这个地址直接从 GitHub 下载指定提交，插件市场也能据此识别仓库更新。

本项目保留包名 `dsh-local-plugin-center`。从旧版本更新时请直接安装上述地址，无需卸载，以保留现有组件设置。离线安装包见 [Releases](https://github.com/TanukiRei/dsh-tanuki-toolbox/releases)。

## 组件

工具箱默认提供模型屏蔽功能：启用“设置优化 → 模型”后，在 **设置 → 模型** 的服务和模型行旁管理开关。关闭后从 DSH 模型目录和选择列表隐藏，并在宿主请求准备及实际派发前拦截。已有对话仍选中该模型时，仅为该对话保留灰色、不可再选择的占位项，禁止发送并显示“该模型已禁用”；切换其他模型后移除占位并恢复发送。不会自动切换其他模型，已在发送中的请求不强制中断，草稿保留。限制保存在当前 profile，重新开启即可恢复；限制执行属于默认功能，关闭设置优化也不会清除已保存的开关，关闭工具箱本体后不再拦截。

设置标题旁显示 DSH 版本；“打开配置文件”左侧的“更新系统”按钮打开原生更新流程，没有可用更新时显示灰色“已是最新”。此入口属于默认功能；设置入口的更新气泡由消息中心的“系统更新”与全局气泡开关控制。

| 组件 | 功能 |
| --- | --- |
| 启动 | 增加启动相关的优化处理；保护启动控制第三方插件检查、旧认证 Cookie 整理与快捷方式接管，开机启动可独立开启。 |
| 快捷栏 | 编辑左侧入口的顺序与显示状态；工作区可收起、拖动调整宽度并保存，支持一键重启。 |
| 起始页 | 查看日期、对话／任务概览、昨日已记录 Token、近期活动与受支持的账号额度。 |
| 会话优化 | 时间统计、模型与推理等级卡片、受支持的速度控制，任务文件的右键操作，以及复用原生菜单的会话列表右键操作。 |
| 回收站 | 使用工作区式任务列表和原生对话／轨迹页面，兼容底部栏与右侧边栏，保留统计；输入区替换为恢复按钮和完全删除倒计时。保留 30 天，支持右键永久删除和确认后清空。 |
| 规则 | 每个任务独立编辑规则，自动保存；每轮正式请求加入当前完整规则，可拖出独立编辑窗。 |
| 设置优化 | 紧凑的模型管理，支持服务与模型排序、开关、默认选择及独立编辑弹窗。 |
| 消息中心 | 顶部灵动岛、系统通知、持久气泡与提示音；可按来源控制通知和对应气泡。 |
| 插件中心 | 区分官方与第三方插件，提供搜索、版本号、自定义名称、更新入口及「插件市场」集成。 |

Windows 的一键重启长按 1 秒触发。后台程序确认当前实例与重开入口后先关闭 DSH，再通过原有保护入口完成检查并重新打开；没有额外的固定等待，也不自动重试。请在任务与插件安装完成后使用。

组件按需加载；关闭组件不会在冷启动时预载该组件的功能代码。已加载模块可能仍保留在引擎缓存中，详见 [生命周期说明](LIFECYCLE.txt)。工具箱自有界面跟随 DSH 的语言：简体、繁体及其他 `zh` 中文变体统一使用中文，其他语言统一使用英文；不改写 DSH 的语言设置。第三方插件与用户内容保留原始文本。

消息中心的“允许通知”使用插件、任务、系统更新三个按钮，点亮为绿色，悬停可查看说明；系统更新专指 DSH 本体更新。灵动岛、系统通知、全局气泡与提示音分别开关。关闭灵动岛只隐藏应用内顶部消息，不影响其余通道，重新开启不补播旧消息。通知来源按钮同时控制对应提醒和气泡：关闭“插件”隐藏插件入口、插件详情及“更新全部”等相关气泡，关闭“任务”隐藏任务相关气泡；重新开启后恢复当前仍有效的状态。全局气泡总开关仍需开启，气泡状态颜色不变。安全启动确认属于一般消息，点击进入“插件中心 → 已安装 → 第三方”。

启用“设置优化 → 模型”后，顶部可添加服务并选择默认模型及推理等级；对话框的还原按钮读取该默认选择。服务和模型使用侧栏同款六点手柄，拖动使用指针捕获并以白色横线提示插入位置，回到原行也保留提示，可用 Alt＋上下键调整；顺序持久保存并同步到对话框选择列表，停用不改变原位置。名称和开关等列表操作自动保存；服务的密钥、名称、地址、协议和模型详细参数分别在弹窗中编辑，提供保存、取消及未保存提示。恢复默认模型和获取可用模型保留独立按钮，不再显示底部重复的“模型启用”模块。推理等级保留 DSH 自带翻译。

设置窗口首次打开后保留当前页面和页面状态，关闭改为带动画隐藏，再次点击设置继续上次页面；隐藏期间移除焦点约束，模型页停止自己的读取订阅。此行为属于默认功能，没有额外组件开关。应用退出或工具箱停用时仍释放窗口。

在模型设置中选定默认值后，该值单独保存并固定；会话中临时切换模型或推理等级只影响该会话，不再覆盖固定默认值。新会话与还原按钮使用固定默认，DSH 原生配置也同步该选择。

灵动岛消息从应用顶部进入，每条显示 8 秒，最多同时保留最新两条；新消息将旧消息向下推，第三条会挤出最旧消息。悬停不暂停倒计时。插件中心提供昵称/原名搜索，官方插件以等高卡片区分正式版与实验性插件；更新查询状态只在插件中心显示文字。

组件关闭后自动收起细分设置；重新展开查看时，下属选项变灰且不可修改，已保存的子项选择保留。

主页提供日期、对话/任务概览、昨日已记录 Token、近七天活动、最近对话与当前任务。已启用且登录 Codex 订阅插件时可读取其额度；统计范围与缺失值说明见页面及变更记录。

## 任务规则

启用“规则”组件后，对话框中“工作区内修改”的右侧显示天平图标和规则数。点击向上展开，逐行编辑并自动保存；回车新增一行，点击外部或再次点击按钮收起。每个任务分别保存，空白规则不改变原生请求。 规则右侧的绿点可逐条停用（灰色）或启用，垃圾桶直接删除；悬停超过 1 秒显示完整内容。停用的规则不会加入模型请求。分叉会话在创建时复制当前规则的内容、顺序和启停状态，之后父子会话独立修改。

规则只在正式任务请求派发时加入一次，不写入聊天记录或压缩来源；修改后下一次请求使用最新版本。上下文压缩结束后的正式请求重新读取完整规则，同时保留 DSH 原有系统、工具与权限约束。规则本身仍占用上下文，过长会拒绝发送并提示缩短，不静默截断；模型是否遵从仍取决于其能力。

拖动编辑栏顶部可打开 Windows 原生独立窗口，拖动边缘改变大小。它归属于当前 DSH 窗口，始终位于 DSH 之上，可被其他应用遮挡并随 DSH 最小化。再次点击对话框的“规则”按钮会收回独立窗并展开编辑栏；顶部收回按钮同样可用。关闭独立窗不删除规则。弹出与独立编辑窗共用同一渲染器、样式和翻译，保持图标、粗体标题、行号、编辑行与操作一致。独立窗使用系统已安装的 WebView2 Runtime（本插件不安装或更新 Runtime）；缺失时保留应用内编辑。其他平台先提供应用内可拖动、缩放的悬浮编辑栏，不提供跨窗口原生显示。关闭组件会停用注入并关闭编辑窗；已保存的规则保留供重新开启。

## 更新

安装并启用「插件市场」后，可以在插件中心查看仓库发布的更新并点击更新。经所有者明确要求发布后，才同步到 `main`，并保留版本标签和 `.tgz` 发布包；版本规则见 [VERSIONING.txt](VERSIONING.txt)。不会后台静默安装更新。

## 兼容性

包声明支持 DSH `>=0.2.0-rc.2 <0.3.0`。部分界面功能依赖 DSH 当前页面结构，宿主更新后可能需要适配。快捷方式接管、登录自启动和强制重启工具用于 Windows；macOS 会禁用这些专用操作，并保留运行中明确版本不兼容插件检查。Mac 界面按窗口/全屏状态避让标题栏，系统通知激活使用系统应用打开机制。

启动保护仅检查明确声明的版本不兼容，不保证拦截未声明的运行时故障。直接启动 DSH 原始程序不会经过快捷方式保护；Windows 缓存的固定入口可能需要重新固定。

## 开发

```text
node scripts/build.cjs
```

该命令使用仓库内的模板和资源重新生成 `client.js` 与 `client-chunks/`，无需安装构建依赖。保护启动器的 C# 源码和 Windows 可执行文件一起保留；需要修改启动器时运行 `scripts/build-launcher.ps1`。单次重启程序使用 `scripts/build-restart-worker.ps1` 编译，并同时生成源码/二进制摘要；普通构建仅核对摘要，不执行重启。

详细变更记录见 [README.txt](README.txt)，全局消息接口见 [NOTIFICATIONS.txt](NOTIFICATIONS.txt)。遵循项目默认偏好，未明确要求时不运行功能测试；构建与打包不代表功能验收。

## 速度接口接入

开启“设置优化 → 模型”后，兼容 OpenAI Chat Completions 的服务可读取 `{baseURL}/models` 的 `capabilities.service_tiers`。只有明确包含 `priority` 或 `fast` 的直接模型显示速度选择；服务商 ID 和完整模型 ID 保持原样。展开服务可点击“重新读取速度能力”；“获取可用模型”也会同步读取能力。模型卡片的闪电按钮直接切换“标准／快速”，未启用模型卡片时显示于原生模型选择旁。标准明确发送 `service_tier=default`，快速发送 `priority`；默认/还原保留继承中枢（省略速度参数），首次点击明确请求快速。偏好按会话、提供商和模型保存，每轮任务捕获快照；重试、工具续写和继承的子任务不受其他会话改档影响。

按与接口方确认的契约，服务端强制速度策略优先；服务端设置为默认时，使用 DSH 请求的标准或快速。点亮的蓝色实心闪电表示 DSH 请求快速，配色与推理等级一致；实际执行档位以接口返回为准。

闪电按钮的悬停说明显示中枢 SSE 的实际确认：未返回实际档位时只显示“等待确认／未确认”，不会把按钮点亮当作上游已生效。凭据仅由 DSH 宿主读取；能力失败保留配置并提供重读入口，不切换其他账号或模型。此接入需要中枢实际返回上述扩展字段；纯标准目录或不兼容协议不会凭名称开启快速选项。本版本只做构建与静态核查，尚未完成真实中枢联调。

会话列表可直接右键打开原生三个点菜单。新增回收站组件：删除后只读保留 30 天，可恢复至原工作区；到期自动永久删除。回收站与快捷栏同时开启时显示侧栏入口。
